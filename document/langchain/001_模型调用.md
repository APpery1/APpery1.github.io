# 001：模型的调用

> 本篇对应当前项目中的 `app/config.py`、`app/chain.py` 和 `app/main.py`。
>
> 学习目标：理解如何读取模型配置、创建聊天模型、组装一个最小 LangChain LCEL 链，并通过 CLI 发起调用。

---

## 一、我们要解决什么问题？

直接调用大语言模型通常需要完成以下几件事：

1. 准备 API Key 和模型名称。
2. 创建模型客户端。
3. 组织系统提示词和用户问题。
4. 把请求发送给模型。
5. 处理模型返回结果。
6. 如果需要多轮对话，还要保存历史消息。

本项目把这些步骤拆分到了不同文件中：

```text
.env              保存本地配置
app/config.py     读取配置
app/chain.py      创建 Prompt、模型和 LCEL 链
app/main.py       接收命令行输入并调用链
```

---

## 二、配置模型参数

项目使用 `pydantic-settings` 读取环境变量。核心配置定义在 `app/config.py`：

```python
class Settings(BaseSettings):
    model_config = SettingsConfigDict(
        env_file=".env",
        env_file_encoding="utf-8",
        extra="ignore",
    )

    openai_api_key: str | None = None
    openai_base_url: str | None = None
    model_name: str = "gpt-4o-mini"
    temperature: float = 0.2
```

这些 Python 字段会对应环境变量：

| Python 字段 | 环境变量 | 作用 |
|---|---|---|
| `openai_api_key` | `OPENAI_API_KEY` | API 鉴权密钥 |
| `openai_base_url` | `OPENAI_BASE_URL` | OpenAI 或兼容服务的接口地址 |
| `model_name` | `MODEL_NAME` | 模型名称 |
| `temperature` | `TEMPERATURE` | 输出随机性 |
| `log_level` | `LOG_LEVEL` | 日志级别 |

推荐在项目根目录创建 `.env`：

```env
OPENAI_API_KEY=你的_api_key
MODEL_NAME=gpt-4o-mini
TEMPERATURE=0.2
# 使用 OpenAI-compatible 服务时填写
# OPENAI_BASE_URL=https://your-provider.example.com/v1
```

### 为什么不能把 API Key 直接写进代码？

把密钥写进源代码有几个问题：

- 容易提交到 Git 仓库。
- 不同环境切换麻烦。
- 团队协作时不方便管理。

本项目的 `.gitignore` 应该忽略 `.env`。提交代码时可以提交一个不含真实密钥的示例文件，例如 `.env.example`。

## 三、创建聊天模型

`app/chain.py` 中的模型创建代码如下：

```python
model_kwargs = {
    "model": settings.model_name,
    "temperature": settings.temperature,
    "api_key": settings.openai_api_key,
}

if settings.openai_base_url:
    model_kwargs["base_url"] = settings.openai_base_url

model = ChatOpenAI(**model_kwargs)
```

这里使用的是 `langchain_openai` 提供的 `ChatOpenAI`。

```python
from langchain_openai import ChatOpenAI
```

`ChatOpenAI` 是一个聊天模型封装器，它负责：

- 按 OpenAI Chat Completions 需要的格式组织请求。
- 发送 HTTP 请求。
- 处理鉴权信息。
- 将响应转换为 LangChain 的消息对象。

### `temperature` 是什么？

`temperature` 可以理解为输出的随机程度：

- 较低，例如 `0` 或 `0.2`：输出更稳定、严谨，适合问答、代码和数据处理。
- 较高，例如 `0.8` 或 `1.0`：输出更加发散，适合创意写作。

它不是“智力参数”，提高 temperature 不代表模型更聪明，只是让输出选择更有随机性。

### `base_url` 的作用

如果不设置 `OPENAI_BASE_URL`，客户端通常使用默认的 OpenAI 接口地址。

如果使用兼容 OpenAI 协议的第三方服务，可以设置：

```env
OPENAI_BASE_URL=https://your-provider.example.com/v1
MODEL_NAME=your-model
```

是否能够成功调用，取决于该服务是否兼容 OpenAI 的请求格式，以及模型名称和 API Key 是否正确。

## 四、使用 PromptTemplate 组织请求

项目使用聊天提示词模板：

```python
prompt = ChatPromptTemplate.from_messages(
    [
        ("system", SYSTEM_PROMPT),
        MessagesPlaceholder(variable_name="history"),
        ("human", "{question}"),
    ]
)
```

系统提示词是：

```python
SYSTEM_PROMPT = "你是一个有帮助的中文 AI 助手。回答准确、清晰、简洁。"
```

这段模板包含三个部分：

### 1. `system`

告诉模型它应该扮演什么角色、遵循什么行为规范。

### 2. `MessagesPlaceholder`

为历史消息预留位置。第一次调用时可能没有历史；后续调用时会把之前的消息放到这里。

### 3. `human`

表示当前用户输入。`{question}` 是变量，真正调用时传入：

```python
{"question": "什么是 LangChain？"}
```

最终模型看到的消息大致是：

```text
system: 你是一个有帮助的中文 AI 助手。回答准确、清晰、简洁。
human: 什么是 LangChain？
```

有历史时则类似：

```text
system: 你是一个有帮助的中文 AI 助手。回答准确、清晰、简洁。
human: 我叫小明
ai: 你好，小明
human: 我叫什么？
```

## 五、理解 LCEL 链

项目使用管道符 `|` 连接各个步骤：

```python
base_chain = prompt | model | StrOutputParser()
```

这就是 LangChain Expression Language，也就是 LCEL。

可以把它理解为一个数据处理流水线：

```text
输入字典
  ↓
Prompt 模板：生成消息
  ↓
ChatOpenAI：调用模型
  ↓
StrOutputParser：提取字符串
  ↓
最终答案
```

例如：

```python
result = base_chain.invoke({"question": "介绍一下 Python"})
```

输入首先填充 `{question}`，然后传给模型。模型返回的消息对象再经过 `StrOutputParser`，最终得到普通字符串。

### 为什么需要 `StrOutputParser`？

聊天模型通常返回的是 `AIMessage`，其中包含 `content` 等信息。`StrOutputParser` 可以把结果转换成更方便使用的字符串：

```python
"Python 是一种通用编程语言……"
```

这样 CLI 直接 `print()` 就可以显示答案。

### 使用 `JsonOutputParser` 查看结构化结果

有时我们不希望把模型结果处理成普通字符串，而是希望得到结构化的 JSON 数据。例如：

```json
{
  "topic": "LangChain",
  "summary": "用于构建大语言模型应用的框架"
}
```

项目在 `app/chain.py` 中预留了注释切换方式：

```python
# 默认模式：输出字符串
output_parser = StrOutputParser()

# JSON 模式：注释掉上一行，并取消下一行注释
# output_parser = JsonOutputParser()
```

切换后，代码变为：

```python
# output_parser = StrOutputParser()
output_parser = JsonOutputParser()
```

此时 `chain.invoke()` 返回的通常是 Python 字典，而不是字符串：

```python
result = chain.invoke({"question": "请用 JSON 返回 LangChain 的简介"}, config=config)
print(result["topic"])
```

需要注意：`JsonOutputParser` 并不是“返回未经处理的原始 HTTP 响应”。它会读取模型消息中的内容，并把合法 JSON 文本解析为 Python 对象。如果需要查看完整的原始模型消息，可以暂时去掉输出解析器，或者在模型后增加调试日志。

另外，启用 JSON 解析器后，模型必须输出合法 JSON。仅仅使用 `JsonOutputParser` 并不能保证模型一定遵守 JSON 格式；实际项目中通常还应在 Prompt 中明确要求：

```python
("human", "请只返回合法 JSON，不要添加 Markdown 代码块：{question}")
```

如果模型返回普通自然语言、带解释文字或非法 JSON，解析时会抛出异常。

## 六、从 CLI 到模型的完整调用过程

`app/main.py` 中的关键代码是：

```python
settings = get_settings()
chain = build_chain(settings)

config = {"configurable": {"session_id": args.session_id}}

answer = chain.invoke(
    {"question": " ".join(args.question)},
    config=config,
)
print(answer)
```

完整执行过程如下：

1. 用户执行命令：

   ```bash
   python -m app.main "用一句话介绍 LangChain"
   ```

2. `get_settings()` 加载 `.env`。
3. `build_chain(settings)` 检查 API Key 并创建模型链。
4. 用户问题被放入 `question` 字段。
5. `session_id` 被放入 LangChain 的运行配置。
6. 链生成 Prompt 并调用模型。
7. 输出解析器提取文本。
8. CLI 打印最终答案。

单次问答也可以写成概念上的简化形式：

```python
chain.invoke(
    {"question": "你好"},
    config={"configurable": {"session_id": "default"}},
)
```

## 七、为什么没有 API Key 时要主动报错？

`build_chain()` 开头有明确检查：

```python
if not settings.openai_api_key:
    raise RuntimeError(
        "未配置 OPENAI_API_KEY。请复制 .env.example 为 .env 并填写 API Key。"
    )
```

这样做比等到网络请求阶段才报错更容易理解。常见配置错误可以在程序启动时立即发现。

注意：当前仓库如果没有 `.env.example`，可以手动创建一个，内容不要放真实密钥：

```env
OPENAI_API_KEY=
MODEL_NAME=gpt-4o-mini
TEMPERATURE=0.2
```

## 八、运行示例

先安装依赖：

```bash
pip install -e .
```

配置 `.env` 后执行：

```bash
python -m app.main "什么是 LCEL？"
```

进入交互模式：

```bash
python -m app.main
```

输入：

```text
你：我叫小明
AI：你好，小明！
你：我叫什么？
AI：你叫小明。
```

输入 `exit` 或 `quit` 退出。

运行测试：

```bash
pytest -q
```

当前项目的测试使用 Mock，不会真正请求远程模型，因此没有 API Key 也可以运行测试。

## 九、本篇小结

本项目中的最小模型调用链可以概括为：

```python
settings = get_settings()
model = ChatOpenAI(...)
prompt = ChatPromptTemplate.from_messages(...)
chain = prompt | model | StrOutputParser()
answer = chain.invoke({"question": "你好"})
```

需要掌握的核心概念：

- 使用环境变量管理 API Key 和模型配置。
- 使用 `ChatOpenAI` 创建聊天模型客户端。
- 使用 `ChatPromptTemplate` 管理提示词结构。
- 使用 LCEL 的 `|` 连接处理步骤。
- 使用 `StrOutputParser` 获取字符串结果。
- 使用 `invoke()` 执行链。
- 使用 `session_id` 区分不同对话会话。
