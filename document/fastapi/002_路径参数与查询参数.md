# 002：路径参数与查询参数

> 本篇在 001 的 `app` 上增加真正带参数的接口。
>
> 学习目标：分清路径参数和查询参数，会用类型注解做转换和校验，知道 `Path()` / `Query()` 以及 `Annotated` 怎么写。

---

## 一、我们要解决什么问题？

图书详情不可能写死成 `/book-1`、`/book-2`。客户端会请求：

```text
GET /books/3
GET /books?author=张三&limit=10
GET /books/3?include_price=true
```

这里有两类参数：

| 类型 | 出现位置 | 例子 | 典型用途 |
|---|---|---|---|
| 路径参数 path | URL 路径里，用 `{}` 声明 | `/books/{book_id}` | 定位**某一个**资源 |
| 查询参数 query | `?` 后面的键值 | `?author=张三&limit=10` | 过滤、分页、开关 |

FastAPI 靠**函数参数名 + 类型注解 + 有没有默认值**来判断这是哪一种，绝大多数情况下你不用手动说“这是 query”。

---

## 二、路径参数

```python
from fastapi import FastAPI

app = FastAPI()

BOOKS = {
    1: {"id": 1, "title": "FastAPI 入门", "author": "张三"},
    2: {"id": 2, "title": "Python 基础", "author": "李四"},
}


@app.get("/books/{book_id}")
def get_book(book_id: int):
    book = BOOKS.get(book_id)
    if book is None:
        return {"error": "未找到图书"}
    return book
```

路径写成 `"/books/{book_id}"`，函数里就有同名参数 `book_id`。两边名字必须一致。

访问 `/books/1`，`book_id` 已经是整数 `1`，不是字符串 `"1"`。这是类型注解的第一个好处：框架先做转换。

访问 `/books/abc` 不会进入函数，直接返回 422：

```json
{
  "detail": [
    {
      "type": "int_parsing",
      "loc": ["path", "book_id"],
      "msg": "Input should be a valid integer, unable to parse string as an integer",
      "input": "abc"
    }
  ]
}
```

读这份错误的方法：

- `loc`：错在哪。`["path", "book_id"]` 表示路径参数 `book_id`。
- `msg` / `type`：什么错。
- `input`：客户端实际传了什么。

后面请求体校验失败时，错误形状相同，只是 `loc` 会变成 `["body", "price"]` 这类。

### 路径里可以有多个变量

```python
@app.get("/authors/{author_id}/books/{book_id}")
def get_author_book(author_id: int, book_id: int):
    return {"author_id": author_id, "book_id": book_id}
```

顺序按 URL 出现即可。函数参数顺序不必和 URL 完全一致，但建议一致，读起来省事。

### 静态路径要比变量路径更具体

如果同时有：

```python
@app.get("/books/me")
def get_my_books():
    return {"mine": True}


@app.get("/books/{book_id}")
def get_book(book_id: int):
    return {"book_id": book_id}
```

必须先声明 `/books/me`。否则 `me` 会被当成 `book_id`，而 `me` 又不是 int，变成 422。

匹配规则是：**按声明顺序找第一条能匹配的路由**。固定字符串比 `{book_id}` 更特殊，所以写在前面。

## 三、查询参数

函数里**没有**出现在路径 `{}` 中的参数，默认就是查询参数。

```python
@app.get("/books")
def list_books(author: str | None = None, limit: int = 10):
    items = list(BOOKS.values())
    if author:
        items = [b for b in items if b["author"] == author]
    return items[:limit]
```

对应请求：

```text
GET /books
GET /books?author=张三
GET /books?author=张三&limit=2
GET /books?limit=1
```

判断有没有默认值：

| 写法 | 含义 |
|---|---|
| `limit: int` | **必填**查询参数。不传则 422 |
| `limit: int = 10` | 可选，默认 10 |
| `author: str \| None = None` | 可选，不传就是 `None` |

注意：`author: str = None` 在类型上是自相矛盾的（注解是 str，默认却是 None）。请写成 `str | None = None`。Pydantic v2 / 较新的 FastAPI 对这种不规范注解会警告或报错。

布尔查询参数会按常见真值解析：

```python
@app.get("/books")
def list_books(in_stock: bool = False):
    return {"in_stock": in_stock}
```

这些都会变成 `True`：`1`、`true`、`True`、`on`、`yes`。

这些都会变成 `False`：`0`、`false`、`False`、`off`、`no`。

## 四、路径参数和查询参数可以同时出现

```python
@app.get("/books/{book_id}")
def get_book(book_id: int, include_author: bool = True):
    book = BOOKS.get(book_id)
    if book is None:
        return {"error": "未找到图书"}
    if not include_author:
        return {"id": book["id"], "title": book["title"]}
    return book
```

```text
GET /books/1
GET /books/1?include_author=false
```

记忆口诀：

```text
/books/{book_id}?include_author=false
        ^^^^^^^^  ^^^^^^^^^^^^^^^^^^
        路径参数        查询参数
```

FastAPI 看的是参数**从哪里来**，不是看函数参数写在第几位。下面这样也能工作，只是不推荐：

```python
def get_book(include_author: bool = True, book_id: int = ...):  # 别这么写
    ...
```

路径参数应当没有默认值（它本来就在 URL 里），查询参数按需给默认值。

## 五、用 `Query` 和 `Path` 加约束

只写 `limit: int = 10` 无法表达“最大 100、最小 1”。这时用 `Query`、`Path`。

当前官方推荐写法是 `Annotated`：

```python
from typing import Annotated

from fastapi import FastAPI, Path, Query

app = FastAPI()


@app.get("/books/{book_id}")
def get_book(
    book_id: Annotated[int, Path(ge=1, description="图书 ID，从 1 开始")],
    q: Annotated[
        str | None,
        Query(min_length=1, max_length=50, description="标题关键词"),
    ] = None,
    limit: Annotated[int, Query(ge=1, le=100)] = 10,
):
    return {"book_id": book_id, "q": q, "limit": limit}
```

`Annotated[类型, 额外信息]` 的意思是：这个参数的类型是左边那个，右边是给框架看的元数据。FastAPI 读到 `Query(...)` 就知道它是查询参数，并套用 `min_length` 等规则。

旧写法仍然能见到，读别人代码时认识即可：

```python
def get_book(
    book_id: int = Path(ge=1),
    q: str | None = Query(default=None, max_length=50),
):
    ...
```

新代码优先 `Annotated`，默认值单独写在 `=` 后面，类型部分更干净。

常用约束：

| 参数 | 适用 | 含义 |
|---|---|---|
| `ge` / `gt` | 数字 | 大于等于 / 大于 |
| `le` / `lt` | 数字 | 小于等于 / 小于 |
| `min_length` / `max_length` | 字符串 | 长度 |
| `pattern` | 字符串 | 正则，例如 `^[a-z]+$` |
| `description` | 任意 | 出现在 /docs |
| `examples` | 任意 | 文档中的示例值 |
| `deprecated=True` | 任意 | 文档里标记即将废弃 |

`limit=1000` 若声明了 `le=100`，一样是 422，进不了函数。把边界写在参数上，业务代码里就少很多 `if limit > 100`。

## 六、枚举：把可取值写死

状态、排序字段这类只允许几个字符串时，用 Enum：

```python
from enum import Enum

from fastapi import FastAPI

app = FastAPI()


class BookSort(str, Enum):
    title = "title"
    year = "year"
    price = "price"


@app.get("/books")
def list_books(sort_by: BookSort = BookSort.title):
    return {"sort_by": sort_by}
```

文档里这个参数会变成下拉框。传入 `?sort_by=author` 会 422。

继承 `str, Enum` 是为了让序列化结果是 `"title"` 这种字符串，而不是难用的枚举对象字符串。

## 七、列表查询参数

想接收 `?tag=python&tag=api`：

```python
from typing import Annotated

from fastapi import Query


@app.get("/books")
def list_books(tag: Annotated[list[str] | None, Query()] = None):
    return {"tags": tag}
```

必须显式 `Query()`，否则 FastAPI 可能把它当成请求体。这是少数“光靠类型不够，要标明来源”的情况。

也可以用逗号分隔的一种习惯（需自己 split），但和 OpenAPI 的 array 风格相比，多值 query 更标准。

## 八、不要把不该出现在 URL 里的东西放进 query

查询参数会完整出现在：

- 浏览器历史
- 服务器访问日志
- Referer
- 公司代理

因此 **密码、token、身份证号不要放 query**。登录放到 003 的请求体，认证放到 009 的 Header。

路径参数适合资源 ID：`/books/1`。用 `/books?id=1` 也能查到一本，但 REST 习惯是：

- 集合：`GET /books`
- 单个：`GET /books/{id}`

筛选、分页才用 query：`GET /books?author=张三&limit=10&offset=0`。

## 九、本篇可运行示例

```python
from enum import Enum
from typing import Annotated

from fastapi import FastAPI, Path, Query

app = FastAPI(title="图书管理 API")

BOOKS = {
    1: {"id": 1, "title": "FastAPI 入门", "author": "张三", "year": 2024},
    2: {"id": 2, "title": "Python 基础", "author": "李四", "year": 2023},
    3: {"id": 3, "title": "HTTP 详解", "author": "张三", "year": 2022},
}


class BookSort(str, Enum):
    title = "title"
    year = "year"


@app.get("/books")
def list_books(
    author: Annotated[str | None, Query(description="按作者精确筛选")] = None,
    q: Annotated[str | None, Query(min_length=1, max_length=50)] = None,
    sort_by: BookSort = BookSort.title,
    limit: Annotated[int, Query(ge=1, le=100)] = 10,
):
    items = list(BOOKS.values())
    if author:
        items = [b for b in items if b["author"] == author]
    if q:
        items = [b for b in items if q in b["title"]]
    reverse = sort_by == BookSort.year
    items = sorted(items, key=lambda b: b[sort_by.value], reverse=reverse)
    return items[:limit]


@app.get("/books/{book_id}")
def get_book(
    book_id: Annotated[int, Path(ge=1, description="图书 ID")],
):
    book = BOOKS.get(book_id)
    if book is None:
        return {"error": "未找到图书"}
    return book
```

试这些 URL：

```text
GET /books
GET /books?author=张三
GET /books?q=Python
GET /books?sort_by=year&limit=2
GET /books/1
GET /books/9          # 业务上未找到，目前返回 {"error": ...}
GET /books/abc        # 422
GET /books?limit=0    # 422，因为 ge=1
```

“未找到图书”现在返回的还是 200 + error 字段。这不是 REST 习惯。004 会改成 404。本篇先保证参数层是对的。

## 十、本篇小结

参数从哪里来：

```text
GET /books/{book_id}?author=张三&limit=10
           ^^^^^^^^  ^^^^^^      ^^^^^
           路径参数   查询参数    查询参数
```

对应函数：

```python
def get_something(book_id: int, author: str | None = None, limit: int = 10):
    ...
```

需要掌握的核心概念：

- 名字出现在路径 `{}` 里的是路径参数，其余带默认值的一般是查询参数。
- 类型注解负责转换和校验，失败是 422，函数不会执行。
- 可选查询参数写成 `T | None = None`。
- 要加范围、长度、说明时用 `Annotated[..., Path()]` / `Query()`。
- 固定路径写在变量路径前面。
- 列表 query 需要显式 `Query()`。
- 敏感信息不要放 URL。
